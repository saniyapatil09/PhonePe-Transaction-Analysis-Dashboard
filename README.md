# 📊 PhonePe Transaction Analysis Dashboard (March 2026)

An interactive **Power BI** dashboard that analyzes PhonePe transaction data across four service categories: **Insurance, Loans, Money Transfer, and Recharge & Bills**.




## 🎯 Project Overview

This project turns raw transaction data into clear, actionable business insights. The dashboard helps track how each service performs, where revenue comes from, and why payments fail.

## ✨ Key Features

- **Monthly transaction trends**: track transaction volume and value over time
- **Service-wise revenue distribution**: compare Insurance, Loans, Money Transfer, and Recharge & Bills
- **Payment failure analysis**: identify the top reasons transactions fail
- **Interactive filters and slicers**: drill down by service, month, and more

## 🛠️ Tools & Technologies

| Tool | Purpose |
|------|---------|
| **Power BI** | Dashboard design, DAX measures, visualizations |
| **Microsoft Excel** | Data cleaning and preparation |
| **Power Query** | Data transformation |
| **Data Modeling** | Relationships and star-schema design |

## 🔄 Workflow

1. **Data Cleaning**: removed duplicates, handled missing values, standardized formats in Excel
2. **Transformation**: shaped and prepared data using Power Query
3. **Data Modeling**: built relationships between tables in Power BI
4. **Visualization**: created interactive charts, KPI cards, and slicers
5. **Insights**: derived business takeaways from trends and failure patterns
